# Changelog

## 2.130 for SourceMod 1.12 – 2026-10-28

War3Source 2.130 (last upstream commit `09be370`, July 2016) updated for SourceMod 1.12 (and 1.13 dev) and
Counter-Strike: Source as of 2025. Every race, shop item and chat command was tested on a CS:S server with bots
(see [test/README.md](test/README.md)).

### Compilation

The upstream code no longer compiled with SourceMod 1.11 or later: all 107 plugins failed. They now build without
error or warning with the SourceMod 1.12 and 1.13 compilers. The release package is built with the 1.12 compiler (1.13 builds
do not load on SourceMod 1.12).

- Removed syntax: array-based enum structs (`W3PlayerProp`, `W3SkillProp`, `W3BuffProperties` are now plain
  indexes, `CooldownClass` and `GenericSkillClass` real `enum struct`s), `while ... do`, `{n}` string indexing,
  function without braces, `Address` arithmetic.
- Errors the old compiler ignored: misspelled tags (`War3Var`, `W3BuffSourceType`), undefined variables in unused
  stocks, ward forwards declared twice, float functions returning untagged values.
- Deprecated natives replaced (`FloatMul`, `FloatDiv`, `GetMaxClients`, `FindDataMapOffs`).

### Game fixes

- **Corrupted Disciple – Static Discharge** healed the *enemies* around the player instead of the player and
  teammates.
- **Luna – Lunar Blessing** gave its bonus damage to nearby *enemies* instead of allies.
- **Effects that lasted forever**: when the last player of a race changes race, War3Source disables the race, and a
  disabled race ignores its own timers, including the ones that end stuns, bashes and slows it put on other players.
  A Chronosphere could freeze its victims until the map changed. Disabling a race now removes every buff and debuff
  it still holds, and the timers that end an effect (Chronosphere, Big Bad Voodoo, God's Strength, Scout
  invisibility, Rarity's sleep and Smitten, Rainbow Dash's speed, Fluttershy) always run. Rainbow Dash and Rarity
  also kept the handle of a finished timer and used it again ("Invalid timer handle" errors in long games).
- **Bots** often ended up with no skill at all: the bot addon checked the skill limit with the level before the new
  point, so it could put one point too many, and War3Source then cleared every skill. It also never counted the
  ultimate (skills counted from 0 instead of 1).
- Missing CS:S assets: Luna's sound, Chronos' sprite and Warden's knife material replaced by stock game files.
- Stock game sounds and models (inside the VPK files, or in `custom/`) were reported as missing and not
  precached (`sound/ui/hint.wav`).
- Attribute short names were always empty (`sizeof` of an integer), shop items 2 skipped the last player slot,
  the race category menu never showed its "new races" count, the Lich ultimate message showed the theoretical
  damage instead of the damage dealt, a player-info menu never closed its handle, a Blood Mage fire effect
  position was computed and dropped.

### Setup

- **Works out of the box with SQLite.** SourceMod's `default` database is MySQL on localhost, so a fresh install
  could not save XP. If the `default` database is unreachable, War3Source now uses SourceMod's local SQLite
  database (`storage-local`); a database named in `war3source.ini` never falls back. On MySQL, connections and new
  tables use `utf8mb4`.
- Errors are logged by default (`war3_log_level 2`; only critical errors were).
- `cfg/war3source.cfg` lists every `war3_` setting of the CS:S plugins with its default value (generated by
  `tools/gen_cfg.py`).
- `tools/build.sh` builds the CS:S package; plugins for other games (TF2, Left 4 Dead) go to
  `plugins/disabled`, so they no longer print "Failed to load plugin" at every start.

### Removed or replaced

- **Statistics, Stats Socket 2 and Updater** moved to [optional/online-stats](optional/online-stats) and are not
  installed. They sent kills, SteamIDs and player IPs to `ownageclan.com`, a domain that no longer belongs to the
  project, and downloaded updates from it. The old socket extension binary (2011) was removed with them.
- **Clan Bonus XP** used SteamTools, abandoned since 2017; it now uses
  [SteamWorks](https://github.com/KyleSanderson/SteamWorks) to check group membership when `war3_bonusclan_id` is
  set; otherwise (or without SteamWorks) the clan tag is checked. Before, the clan tag was ignored whenever the
  extension was loaded.
- Links to `war3source.com` (dead) and `ownageclan.com` replaced by the GitHub repository (intro menu,
  translations, plugin information); the intro menu shows the server name when `war3_introclanname` is empty.
